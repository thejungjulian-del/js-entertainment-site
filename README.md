# JS Entertainment site

The public website for JS Entertainment, a talent company I'm building around groups that are part music act, part creators. The parent page is a white "paper edition" layout with a hairline grid and flat-shaded 3D shapes that turn in the roster. It links through to the site for A Loud Peace, the first group, which is dark on purpose and opens on a short debut film (`aloudpeace/loud-room.html`).

## Run it

Plain HTML, CSS and JavaScript with no build step. The brand font is inlined in the pages.

```
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Status

Pre-launch. The pages are finished designs, but the group hasn't debuted and the sign-up and booking forms are styled only and don't send anywhere yet.
